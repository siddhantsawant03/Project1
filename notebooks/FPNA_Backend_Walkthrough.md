# FP&A Backend Analysis Walkthrough

Open this file in VS Code and use it as the guided walkthrough for the backend analysis.

## 1. Data and controls
- `data/processed/fpna_model.csv`
- `outputs/data_quality.csv`

## 2. SQL analysis
Run/review:
- `sql/01_management_pnl.sql`
- `sql/02_budget_vs_actual.sql`
- `sql/03_cost_centre_drivers.sql`
- `sql/04_forecast.sql`
- `sql/05_data_quality.sql`

## 3. Python model
Start with `src/model.py` and follow:
1. transaction normalization
2. account categorisation
3. monthly P&L construction
4. budget vs actual
5. cost-centre analysis
6. variance drivers

## 4. Forecasting
Review `src/forecasting.py` and the forecast outputs generated by the pipeline.

## 5. Scenario analysis
Review `src/scenarios.py` for the driver-based planning model.

## 6. Outputs
- `outputs/pnl_monthly.csv`
- `outputs/cost_centre_analysis.csv`
- `outputs/driver_analysis.csv`
- `excel/FPNA_Enterprise_Model.xlsx`

## 7. Presentation layer
Run `python app.py` and open `http://127.0.0.1:5000`.

The dashboard is a presentation layer over the backend analysis; the core project value is the reproducible FP&A model in SQL and Python.
