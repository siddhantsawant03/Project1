# Data Dictionary

The source includes SAP-style accounting fields such as company code (`BUKRS`), document number (`BELNR`), fiscal year (`GJAHR`), period (`MONAT`), posting date (`BUDAT`), G/L account (`HKONT`), cost centre (`KOSTL`), profit centre (`PRCTR`) and local/document amounts (`DMBTR`, `WRBTR`).

Plan versions identify Budget and Rolling Forecast. The source describes 3 company codes, 36 cost centres, 19 G/L accounts, 5 management categories and 48 monthly periods across FY2022–FY2025.
