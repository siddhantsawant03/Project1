# Methodology

Actuals are normalized to month, company code, cost centre and management category. Debit/credit direction is respected where the source provides `SHKZG`. Budget and Rolling Forecast are retained as separate plan versions.

Management P&L:
- Gross Profit = Revenue + COGS
- Operating Profit = Revenue + COGS + Personnel + Opex + Depreciation
- Margin = Operating Profit / Revenue

Variance = Actual - Budget. Favorability depends on account behavior; this prototype keeps the numeric variance transparent and labels the management view as favorable/unfavorable for directional review.

Scenario analysis changes category assumptions against the selected actual baseline. It is not presented as a statistically validated forecast.
